================================================================================
                           VISÃO GERAL DA BIBLIOTECA
================================================================================

A biblioteca ppymavlink é uma implementação completa para controle de drones e
veículos autônomos utilizando o protocolo MAVLink. Ela oferece uma API de alto
nível que abstrai toda a complexidade da comunicação serial/UDP, processamento
de mensagens e gerenciamento de estado.

Principais Características:

- API intuitiva        - Comandos simples e diretos
- Thread-safe          - Estado compartilhado seguro entre threads
- Event-driven         - Sistema de eventos via dispatcher
- Failsafe automático  - Reconexão e ações de emergência
- Health monitoring    - Detecção proativa de problemas
- Rate limiting        - Prevenção de saturação do link
- Validação de entrada - Prevenção de comandos inválidos
- Suporte a missões    - Upload/download/execução de missões
- Navegação guiada     - GOTO, velocidade, yaw control
- Logging estruturado  - Debug e monitoramento facilitados

Mudança de Modo:

    from commands import CommandResult

    # Listar modos disponíveis
    drone.commands.print_available_modes()

    # Mudar modo
    result = drone.set_mode("GUIDED", timeout=3.0)  # Navegação guiada com GPS
    result = drone.set_mode("AUTO", timeout=3.0)    # Executar missão automática
    result = drone.set_mode("RTL", timeout=3.0)     # Return to Launch
    result = drone.set_mode("LAND", timeout=3.0)    # Pousar na posição atual
    result = drone.set_mode("LOITER", timeout=3.0)  # Pairar mantendo posição
    result = drone.set_mode("STABILIZE", timeout=3.0) # Modo estabilizado
    result = drone.set_mode("ALT_HOLD", timeout=3.0)  # Manter altitude
    result = drone.set_mode("POSHOLD", timeout=3.0)   # Manter posição

    # Verificar modo atual
    print(f"Modo atual: {drone.state.flight_mode()}")

    # Atalhos
    drone.commands.rtl()        # Ativa RTL
    drone.commands.hold()       # Ativa LOITER (ou HOLD)
    drone.commands.auto()       # Ativa AUTO
    drone.commands.stabilize()  # Ativa STABILIZE

ARM e DISARM:

    # ARMAR
    result = drone.arm(timeout=5.0)

    if result == CommandResult.SUCCESS:
        print("Armado com sucesso!")
    elif result == CommandResult.TIMEOUT:
        print("Timeout - drone não respondeu")
    elif result == CommandResult.DENIED:
        print("Negado - verifique:")
        print("  - GPS fix adequado?")
        print("  - Safety switch pressionado?")
        print("  - Pre-arm checks passaram?")
        print("  - Bateria OK?")
    elif result == CommandResult.FAILED:
        print("Falha geral")
    elif result == CommandResult.DISCONNECTED:
        print("Desconectado!")

    # Verificar se armou
    if drone.state.is_armed():
        print("Drone está armado")

    # DESARMAR
    drone.disarm(timeout=5.0)

    # Forçar desarme (CUIDADO! Pode desarmar em voo!)
    drone.commands.force_disarm()

Decolagem e Pouso:

    # Decolagem (requer modo GUIDED e armado)
    drone.set_mode("GUIDED")
    drone.arm()
    result = drone.takeoff(altitude=10.0, timeout=10.0)

    if result == CommandResult.SUCCESS:
        print("Decolagem iniciada!")
        
        # Aguardar atingir altitude
        time.sleep(5)
        print(f"Altitude: {drone.state.position.relative_altitude:.1f}m")
    else:
        print(f"Falha na decolagem: {result}")

    # Pousar
    drone.land()

    # Aguardar pouso completo
    while drone.state.is_armed():
        time.sleep(1)
    print("Pouso concluído!")

    # Abortar pouso (se necessário)
    drone.commands.abort_landing()

Reboot:

    # Reiniciar apenas o autopilot
    result = drone.reboot(autopilot_only=True)

    # Reiniciar sistema completo (CUIDADO!)
    result = drone.reboot(autopilot_only=False)

        vz=0.0,        # Velocidade vertical (m/s, positivo=descer)
        yaw=None,      # Yaw opcional
        duration=3.0   # Duração em segundos (None = contínuo)

    # Velocidade contínua (até mandar parar)
    drone.set_velocity(vx=2.0, vy=1.0, vz=0.0)  # Diagonal nordeste

    # Velocidade no referencial do corpo (body frame)
    drone.set_velocity_body(
        vx=3.0,   # Frente (m/s)
        vy=0.0,   # Direita (m/s)
        vz=0.0,   # Baixo (m/s)
        duration=5.0
    )

Controle de Yaw (Orientação):

    # Yaw absoluto (apontar para norte = 0°)

    drone.set_yaw(90)      # Leste
    drone.set_yaw(180)     # Sul
    drone.set_yaw(270)     # Oeste

    # Yaw relativo (girar X graus)
    drone.set_yaw(90, is_relative=True)    # Gira 90° horário
    drone.set_yaw(-45, is_relative=True)   # Gira 45° anti-horário

    # Direção específica
    drone.set_yaw(180, direction=1)   # Força sentido horário
    drone.set_yaw(180, direction=-1)  # Força sentido anti-horário

    # Taxa de yaw (rotação contínua)
    drone.set_yaw_rate(30, duration=3.0)   # 30°/s por 3 segundos
    drone.set_yaw_rate(-15, duration=2.0)  # 15°/s anti-horário por 2s

O Rate Limiter previne saturação do link de comunicação limitando a frequência
de mensagens.

Configuração:

    from rate_limiter import LimitStrategy

    # Configurar intervalo mínimo entre mensagens (segundos)
    drone.configure_rate_limit("GOTO", interval=1.0)        # Máx 1 GOTO por segundo
    drone.configure_rate_limit("VELOCITY", interval=0.2)    # Máx 5 comandos/s
    drone.configure_rate_limit("PARAM_SET", interval=0.5)   # Máx 2 parâmetros/s

    # Configurar estratégia para quando exceder o limite
    drone.configure_rate_limit_strategy("GOTO", LimitStrategy.BLOCK)   # Bloqueia até poder
    drone.configure_rate_limit_strategy("HEARTBEAT", LimitStrategy.DROP) # Descarta excedentes
    drone.configure_rate_limit_strategy("PARAM_SET", LimitStrategy.QUEUE) # Enfileira

Estratégias:

    | Estratégia | Comportamento                                   |
    |------------|-------------------------------------------------|
    | DROP       | Descarta mensagens que excedem o limite         |
    | QUEUE      | Enfileira mensagens para enviar depois          |
    | BLOCK      | Bloqueia até poder enviar (padrão)              |

        print("=== VERIFICAÇÃO PRÉ-VOO ===")
        checks = [
            ("Conectado", drone.is_connected),
            ("GPS Fix", drone.state.has_gps_fix()),
            ("Bateria > 10.5V", drone.state.battery.voltage and drone.state.battery.voltage > 10.5),
            ("Modo válido", drone.state.flight_mode() != "UNKNOWN"),
        ]
        
        all_ok = True
        for name, ok in checks:
            status = "✅" if ok else "❌"
            print(f"{status} {name}")
            if not ok:
                all_ok = False
        
        if not all_ok:
            print("❌ Verificações falharam. Abortando.")
            return False
        
        # Preparar para voo
        print("\n🎮 Preparando para voo...")
        drone.set_mode("GUIDED")
        
        # Armar

        result = drone.arm()
        if result != CommandResult.SUCCESS:
            print(f"❌ Falha ao armar: {result}")
            return False
        
        # Decolar
        print("🛫 Decolando para 10 metros...")
        result = drone.takeoff_guided(10.0, timeout=15.0)
        if result != NavResult.SUCCESS:
            print(f"❌ Falha na decolagem: {result}")
            drone.disarm()
            return False
        
        # Pairar por 5 segundos
        print("⏱️ Pairando...")
        time.sleep(5)
        
        # Pousar
        print("🛬 Pousando...")
        drone.land()

================================================================================
                                DICAS IMPORTANTES
================================================================================

1. SEMPRE aguarde telemetria após conectar: drone.wait_ready(timeout=10)

2. SEMPRE verifique GPS fix antes de armar em modo GUIDED

3. SEMPRE monitore a bateria durante o voo

4. SEMPRE configure o failsafe adequadamente antes de voar

5. TESTE PRIMEIRO no SITL (simulador) antes de voar com hardware real

6. USE CONTEXT MANAGER (with Vehicle(...) as drone:) para garantir desconexão

7. TRATE EXCEÇÕES e use KeyboardInterrupt para interrupção segura

8. MONITORE o estado do link e o health monitor continuamente

9. VALIDE entradas antes de enviar comandos críticos

10. DOCUMENTE suas missões e parâmetros para reprodução
